# 🩺 Diabetes Prediction Using Machine Learning

## 📌 Project Overview

Diabetes Prediction is a Machine Learning project that predicts whether a person is likely to have diabetes based on different health-related features.

The project uses a dataset containing medical information such as glucose level, blood pressure, BMI, age, insulin, and other health parameters. Machine Learning algorithms are trained on the dataset to identify patterns and make predictions.

This project demonstrates how Machine Learning can be used to analyze healthcare data and support diabetes risk prediction.

---

## 🎯 Objectives

* Predict the possibility of diabetes using Machine Learning.
* Analyze health-related data and identify important features.
* Perform data preprocessing and cleaning.
* Train and evaluate a Machine Learning model.
* Generate predictions for new input data.
* Understand the application of Machine Learning in healthcare.

---

## 📊 Dataset

The dataset contains medical and health-related information used to predict diabetes.

### Important Features

* **Pregnancies** – Number of pregnancies
* **Glucose** – Glucose concentration in the blood
* **BloodPressure** – Blood pressure level
* **SkinThickness** – Skin thickness measurement
* **Insulin** – Insulin level
* **BMI** – Body Mass Index
* **DiabetesPedigreeFunction** – Diabetes-related family history measure
* **Age** – Age of the person
* **Outcome** – Target variable indicating diabetes status

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/diabetes-prediction.git
```

Navigate to the project folder:

```bash
cd diabetes-prediction
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

Run Jupyter Notebook:

```bash
jupyter notebook
```
